# JAVARA Tutorials

These tutorials are practical exercises for a local JAVARA instance. Complete
the [getting-started guide](../guide/getting-started.md) first.

## Learning path

1. [Complete a first API workflow](first-api-workflow.md): register a USER,
   sign in, call a protected endpoint, rotate a refresh token, and log out.
2. [Use cookie authentication in a browser](browser-cookie-authentication.md):
   configure CORS, send cookies, and handle CSRF protection.

All examples use local demonstration accounts. Do not copy sample passwords
or tokens into a real deployment.
